- 핵심 수식/조건은 인라인 코드(`) 또는 코드 블록으로 표시

- 반직관적이거나 헷갈리기 쉬운 부분은 반드시 **Q&A 형태**로 설명
- `<br>` 태그로 섹션 간 여백 확보
